## POC v2 구현 결정

`POC_V2_SCOPE.md`가 정하지 않은 빈 곳을 구현 착수 시 에이전트가 메운 값이다. 불변 원칙(`INV-01~08`, V2-DEC)을 바꾸지 않으며 **임시 채택 상태**다(사용자 확인 전, [`PROVISIONAL_DECISIONS.md`](PROVISIONAL_DECISIONS.md) TD-01). 바꾸고 싶으면 이 표를 고친다. 수치는 전부 `GameplayTableData.json`에 둔다. 그 밖의 임시 결정도 같은 문서에 있다.

| ID | 결정 | 근거 / 의도 |
| --- | --- | --- |
| V2-IMPL-01 | **`feature/poc-v2`는 `feature/poc-core` 위에 쌓는다.** `develop` 병합은 사용자 승인 후로 미룬다 | Git Flow의 분기 기준(`develop`)과 다르지만 v1 병합이 아직 결정되지 않았다. 나중에 `develop`으로 재정렬할 수 있다 |
| V2-IMPL-02 | **전투 중 중상이 되면 그 자리에 쓰러진다.** 이동·사격·명령 불가. 적은 어그로 범위에 행동 가능한 인력이 없을 때만 쓰러진 인력을 공격한다 | 기준서의 "방어 불가"를 그대로 따른다. 완전 면역이면 전투 사망이 사라지고(INV-02 약화), 최우선 표적이면 중상이 거의 곧 사망이라 치료 판단이 사라진다. 동료가 구할 수 있다 |

| V2-IMPL-04 | **중상자의 작업·방어 배정은 보존하고 변경은 거부한다**(파견 인력과 같다). 생산 정원은 행동 가능 인력만 센다. 회복했을 때 자리가 찼으면 방어 대기로 돌린다 | 기준서 4.3과 v1 `ResolveReturn` 규칙에 맞춘다 |

| V2-IMPL-06 | **일시정지된 치료는 다음 준비 시작 시 같은 담당자가 행동 가능하면 자동 재개한다.** 불가능하면 새 담당자를 고를 때까지 대기한다. 재개는 무료다. 환자 사망·중상자 아닌 환자의 파견·플레이어 취소는 치료를 끝내며 **환불하지 않는다**. 치료 중 환자는 파견 전에 취소해야 한다 | 이중 차감 금지(7.2 항목 5). 환불이 없어야 치료 시작이 판단이 된다 |

## 작업 지침 적용 범위

POC2 작업 지침과 로그 문서에서 씬 순서, JSON 테이블, MVP, 프로시저럴 생성 지양, 코딩 스타일, 커밋 형식, 로그 계약만 적용한다. 슬롯머신, 상점, 무기, 소지금 항목은 이 게임에 없어 적용하지 않는다.
