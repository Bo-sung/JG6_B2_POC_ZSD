## 11. 단축 사항과 해석 주의

- **타이머:** 전략 행렬은 8배속, UI 세션은 대기 구간에 최대 8배속을 썼다. 단계 강제 진행은 최종 값 판정에 쓰지 않았다. 리뷰 재현(H1·M2)만 디버그 단계 전환과 fixture(`BeginAway`, Warp, HP 설정)를 썼다.
- **전략 구동:** 평가 코드의 클로저가 `GameSession` 공개 API(`TrySetWork`, `TrySetDefensePoint`, `TrySetDefenseStation`, `TryStartExpedition`, `TryPlaceBuilding`, `TryRepairBuilding`, `CommandMove`, `CommandAttack`, `ConfirmResult`)만 호출한다. UI 없이 처리하므로 조작 시간이 0이다. 사람은 파견·건설이 더 늦다.
- **전략은 고정 규칙이다.** 시설 좌표, 큐, 방어 위치를 제가 정했다. "관문별은 약하다"는 이 규칙의 결과이며 최적 플레이의 증명이 아니다. 동쪽 봉쇄+서쪽 집중의 거울 자세는 측정하지 않았다.
- **시드 차이:** 시드는 탐사 결과와 스폰 오프셋만 바꾼다. 탐사 없는 전략의 시드 간 차이는 사실상 물리·AI 잡음이다. L2 수정으로 근거리와 원거리가 같은 난수를 받아 시드 15·777에서 첫 파견 사망이 함께 나온다.
- **표본:** 5개 시드, 보조 전략 2~3개 시드다. 통계적 근거가 아니다.
- **기록 시점:** 지각 측정을 위해 핵심 행렬 뒤에 실행기에 도착 시각·처치 곡선 기록만 추가했다. 게임 동작과 전략 규칙은 같다.
- **입력 설정:** 검증 동안만 Input System 초점 설정을 메모리에서 바꾸고 되돌렸다. Run In Background 오버라이드도 해제했다.
- **플레이어 빌드:** 이번 값으로 재실행하지 않았다.

## 12. 남은 문제

1. **균형 전략의 W2~W3 손실 부족:** 위 판정 참고. 집중 자세의 W2가 특히 안전하다. 수치만으로 더 올리면 관문별 플레이가 먼저 무너진다.
2. **집중 자세 우세:** 봉쇄된 관문의 방벽은 경로가 열려 있는 한 공격받지 않아 비용 8로 영구 효과를 낸다. 수치로 해결되지 않으면 규칙 판단이 필요하며, 이는 이번 범위 밖이므로 결정을 요청한다.
3. **자동 방어 인력은 코어를 지키러 가지 않는다.** 사거리 10이라 관문 초소에서 코어 앞까지 닿지 않는다. 직접 명령의 역할이기는 하지만 처음 하는 플레이어는 코어 앞 적을 놓칠 수 있다. 피드백 확인 필요.
4. **세션 길이와 재미 가설은 사람 측정이 필요하다.**
5. **원거리 귀환의 전투 합류:** 준비 시작에 파견해도 전투 24초 뒤 복귀 지점에 나타나 이동에 약 16초 더 걸린다(약 40초). 집중 자세의 W3(평균 32~33초)에는 늦다. 의도한 비용이지만 사람이 납득하는지는 모른다.
