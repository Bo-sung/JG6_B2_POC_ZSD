# 임시 결정 기록

> 2026-11-06 사용자 지시로 에이전트가 **임시로 정한** 결정이다. 사용자가 승인한 결정이 아니다.
> POC v2가 끝난 뒤 사용자가 검토해 확정하거나 바꾼다. 바꾸고 싶으면 해당 행을 고치고 코디네이터에게 알린다.

## 적용 규칙

- **문서 위계:** 사용자 지시 > `INV-01~08` > `POC_V2_SCOPE.md` 명시 결정 > 이 문서 > v1 상세 규칙 > 기존 코드. 이 문서는 기준서의 빈 곳만 메운다.
- **불변 원칙과 충돌하면 이 문서가 진다.** 충돌을 찾으면 구현을 멈추지 말고 불변 원칙을 따른 뒤 이 문서를 고친다.
- **새 결정:** 워커나 코디네이터가 빈 곳을 찾으면 묻지 않고 정한 뒤 이 문서 끝의 "작업 중 추가"에 적는다.
- **수치:** 모두 초깃값이다. 코드가 아니라 `GameplayTableData.json`에 둔다. G6에서 측정한 뒤 조정할 수 있다.
- **안 하는 일:** 외부 게시, 푸시, 병합, 자격 증명 교체, 전역 설정 변경은 임시로도 실행하지 않는다. 사용자가 지시할 때만 한다.
- **변경 비용:** 쉬움(값이나 문구만 수정), 보통(코드와 테스트 수정), 큼(여러 게이트에 걸친 재작업).
